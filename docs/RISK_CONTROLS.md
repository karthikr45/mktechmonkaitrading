# Risk controls
Implemented: paper-only boundary, kill switch, funds/notional, maximum order value 500000 INR, quantity 100, basic max-position/daily-loss policy functions, 30-second quote freshness, 3% deviation, broker/strategy availability, approval recheck and idempotency conflict. Demo execution uses a synthetic replay clock and only supports buy orders for DEMO-NIFTY. Position and daily-loss values are not yet backed by a portfolio ledger. Weekly/sector/instrument/Greeks exposure, margin, defined-loss/hedge, session calendar and cooldown policies remain pending. This is not a production risk engine.
