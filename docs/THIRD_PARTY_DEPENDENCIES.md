# Third-party dependencies
Next.js, React, NestJS, TypeScript, Zod, Decimal.js, TanStack Query, Lucide, Vitest, Playwright, FastAPI, Pydantic, PostgreSQL/pgvector, Redis, MinIO, Mailpit, Prometheus, Grafana, MLflow and optional Ollama. Exact JavaScript resolutions are captured in pnpm-lock.yaml; Python exact local resolutions are captured in requirements.lock.txt, alongside bounded requirements. Licenses and transitive notices require a distribution review, particularly infrastructure components. No external market/news data is collected. No proprietary analytics implementation is copied.
