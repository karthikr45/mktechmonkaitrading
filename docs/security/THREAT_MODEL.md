# Threat model
Account takeover: production auth/MFA pending; loopback-only demo. Broker-token theft: no tokens consumed or stored yet. Order tampering: schema validation, deterministic risk and approval; durable signatures/version locking pending. Duplicates: scoped idempotency and in-process execution lock; transactional outbox pending. Tenant leakage: engine scoping and enforced SQL RLS; PostgreSQL RLS and transactional isolation checks pass. Prompt injection/malicious documents: AI/RAG unavailable; authorized retrieval/redaction gates required before enabling. Data poisoning: synthetic versioned replay only; provenance checks pending. Denial of service: bounded schemas and loopback exposure; rate limits/quotas pending.
